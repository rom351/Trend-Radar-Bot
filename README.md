# Trend Radar Bot

Бесплатный ежедневный радар товарных трендов на базе GitHub Actions, Groq,
Telegram и Google Sheets.

- каждый день в 05:45 по часовому поясу `Europe/Kyiv`;
- ровно 8 проверенных и не повторяющихся карточек;
- ориентиры закупочной и розничной цены, конкуренция, аудитория, риски и тест;
- защита от повторов за последние 30 дней;
- субботний топ-5 за последние 7 дней;
- один ежедневно обновляемый закреплённый топ-10 за последние 30 дней;
- история хранится в `data/trend_history.json` и очищается старше 60 дней.

Ручной запуск: `Actions` → `Daily Trend Radar` → `Run workflow`.
